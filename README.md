# 🚀 Pooja Singh — Software Engineer Portfolio

A modern, responsive, single-page personal portfolio website built with **React.js**, showcasing my software development skills, projects, education, achievements, certifications, and technical experience.

---

## ✨ Features

- 🖥️ **Single-page portfolio** — Smooth navigation across all sections
- 🎨 **Modern responsive UI** — Optimized for desktop, tablet, and mobile
- 🌙 **Dark/Light theme** — Theme switching support
- 📱 **Android Development section** — Kotlin, Jetpack Compose, Firebase, RoomDB, CameraX and more
- ⚙️ **Backend Development section** — Python, FastAPI, Java, MySQL, PostgreSQL, MongoDB and Redis
- 🤖 **Machine Learning & GenAI section** — OpenAI, FAISS, OpenCV and MediaPipe
- 💻 **Programming & Development Tools** — Java, C++, Kotlin, Python, React, Git and Docker
- 🎓 **Education section** — IIIT Bhagalpur and Avadh Collegiate
- 🏆 **Achievements & Certifications** — Amazon ML Summer School, Flipkart Grid, Myntra WeForShe and professional certifications
- 💼 **Experience & Leadership** — Academic mentoring and Android Development Club experience
- 🚀 **Projects section** — DevMate AI and TriSpark
- 📄 **Resume viewer** — View and access my latest resume
- 📬 **Contact section** — Connect through LinkedIn, GitHub and Email
- 🔗 **Competitive Programming profiles** — LeetCode, Codeforces, CodeChef, GeeksforGeeks and Coding Ninjas
